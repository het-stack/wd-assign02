JavaScript validation in plain English
--------------------------------------
Registration Form

The JavaScript checks that the username has at least five characters and only contains letters,
numbers, or underscores. It also checks the email address, phone number, password strength, and
whether both passwords match. Users must select a gender, at least one movie genre, and a country. If
any information is incorrect or missing, an error message appears.

Recommendation Form

The JavaScript uses simple if/else statements to recommend a movie based on the user's age group
and favourite genre. Children are only recommended suitable G or PG movies. After choosing a movie,
the website displays the recommendation and provides a booking link. The movie name is included in
the link so it can be automatically selected on the booking page.

Booking Form

The JavaScript automatically selects the movie from the booking link. It calculates the ticket price and
total cost based on the movie and number of tickets. It also displays different fields depending on
whether the user chooses voucher or online payment. Before submitting, it checks the name, email,
phone number, screening date, ticket quantity, payment method, and payment details. If anything is
incorrect, an error message appears, and the form cannot be submitted.

Known limitations
-----------------
The site has very little amount of colour contrast, and I am not using the best way to link the URL for some of the buttons.
